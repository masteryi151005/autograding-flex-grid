# Bài tập: Dựng layout bằng CSS Grid và Flexbox

Bạn cần hoàn thành **2 bài trong cùng một assignment**:

- Grid 1: [https://itest.com.vn/lects/webappdev/layout/grid1.htm](https://itest.com.vn/lects/webappdev/layout/grid1.htm)
- Flexbox 2: [https://itest.com.vn/lects/webappdev/layout/flexbox2.htm](https://itest.com.vn/lects/webappdev/layout/flexbox2.htm)

## 1. File cần nộp

Bạn chỉnh sửa đúng 2 file ở thư mục gốc:

- `grid1.htm`
- `flexbox2.htm`

## 2. Yêu cầu bài Grid (`grid1.htm`)

- Có khai báo CSS Grid để tạo bố cục.
- Dựng lại đầy đủ nội dung theo trang đề gốc.

## 3. Yêu cầu bài Flexbox (`flexbox2.htm`)

- Có khai báo CSS Flexbox để tạo bố cục.
- Dựng lại đầy đủ nội dung theo trang đề gốc.
- Nên dùng các thẻ semantic hợp lý (ví dụ: `header`, `main`, `article`, `aside`, `footer`, `section`).

## 4. Cách chấm điểm

Autograding chia thành nhiều test nhỏ theo từng tiêu chí Grid/Flex.  
Mỗi test pass/fail độc lập và cộng điểm theo cấu hình GitHub Classroom.

## 5. Lưu ý

- Giữ đúng tên file và đường dẫn.
- Nội dung chữ cần bám sát đề gốc (autograder có kiểm tra nội dung).
- Bạn có thể tự do chỉnh CSS/HTML miễn là đạt yêu cầu.
